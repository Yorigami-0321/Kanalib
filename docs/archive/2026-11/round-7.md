## 任务 A：F-067 撤销/历史核心（核心线）

- **文件**：新增 `crates/kanalib-core/src/undo.rs`、`state.rs` 操作入口、`db.rs` 必要的精确恢复辅助；不改 schema。
- **范围（只覆盖用户发起、可逆的编辑）**：
  - 收藏切换、星级设置/清除。
  - 手工标签添加/移除；自动标签移除保存原 `TagHit`（category/score/origin）并用精确恢复辅助还原。
  - 批量收藏/星级/手工标签作为一条操作记录，保存每个路径的 before/after。
- **不做**：删除/回收站（仍走系统回收站）、去重评审状态、来源移除、文件系统操作、跨重启持久化。
- **实现约束**：
  - 会话内有界栈（默认 50 条，溢出丢最旧）；`record` / `undo_last` / `can_undo` / `depth` API。
  - 撤销后刷新计数、FTS、选中项与可见索引；失败返回明确错误，不部分回滚已损坏的记录。
  - 不新增 schema；不复制原文件；不改 sidecar。
- **验收**：单测覆盖收藏/星级/手工标签/批量/栈上限/失败路径；撤销后计数与搜索一致；无数据库迁移。

## 任务 B：F-067 UI（唯一 UI 车道）

- **文件**：`app.rs`、`inspector.rs`、`tags.rs`、`status_bar.rs`；`app.rs` 仍单点写入。
- **内容**：
  - `Ctrl+Z` 撤销上一条；命令面板「撤销上一步」；成功 toast「已撤销 · 标签/收藏/星级」。
  - 检查器/批量栏的收藏、星级、手工标签操作接入记录；底栏或命令面板显示可撤销条数（轻量）。
  - 失败/不可撤销（删除、来源移除）明确提示，不伪装成功。
- **不做**：历史面板/跨重启历史、删除撤销、真实外部验收。
- **验收**：隔离数据根截图/UIA；Ctrl+Z 恢复标签/星级/收藏并刷新计数；`cargo check --workspace`、`cargo test --workspace`。
