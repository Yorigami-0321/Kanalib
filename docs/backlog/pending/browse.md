# 浏览与查看

> 上级索引：[../README.md](../README.md) · 文档地图：[README](../README.md)

## F-003 图片对比

- **依据**：`PLAN.md` §6.2 的去重比较卡片；digiKam 的 Light Table 支持多图并排。
- **现状**：去重详情已有并排卡片与差异表（`lib.rs:4645-4714`、`7073`），但只是缩略图；相似组无法同步缩放/平移，也不能对任意 2–4 张选中图发起对比。
- **建议**：新增对比模式，支持“当前去重组”或“选中 2–4 张”；左右/网格布局；同步缩放与中心点；显示文件名、尺寸、大小、星级、标签差异；标出保留项；复用 `ThumbCache`，不新开无界缓存。
- **验收**：对比中缩放/平移同步；差异字段高亮；可切换保留项；Esc 返回原视图；100,000 张库中只加载当前对比图。
- **依赖/风险**：窄窗口下的布局；不同长宽比的图片对齐；依赖 F-001 的图片缓存。

## F-004 以图找相似

- **依据**：`PLAN.md` §6.2 的 pHash 基础设施；Eagle 的“以图搜图”。
- **现状**：只有全库相似扫描，把整个图库分成组；没有“以选中这张图为锚点，找相似图”的入口。pHash 已存于 `Asset.phash`，无需重新解码。
- **建议**：检查器与右键菜单增加“查找相似”；读取库内 pHash，并行计算汉明距离，按距离排序成临时结果视图；提供与去重相似的阈值选择；可一键“加入相似组审核”，但不自动删除。
- **验收**：100,000 张暖库单张查询 ≤ 300ms；结果按距离升序显示距离/相似度；阈值改变即时重排；结果视图支持选择、快速查看、右键与批量操作。
- **依赖/风险**：与 F-045 的阈值语义保持一致；链式合并只用于去重分组，不用于单张查询结果。

## F-005 分组浏览与时间线

- **依据**：Windows Explorer 的“分组依据”；digiKam/PhotoPrism 的时间线浏览。
- **现状**：图库是平铺网格，只有排序，没有组标题；此前视图改版把分组列为不在本期范围，F-005 现单独立项。
- **建议**：在 F-001 的行/网格渲染上增加“按修改时间 / 拍摄时间 / 来源 / 评级 / 自动归类”分组；组头吸顶、可折叠、显示组内数量；时间线按日/月分段；键盘跨越组时保持可见。
- **验收**：10 万资产按日期分组滚动不劣于 F-001 基线；组头吸顶；折叠后行数减少；切换排序/筛选后分组重建正确。
- **依赖/风险**：依赖 F-001 的行布局；按拍摄时间分组依赖 F-034；分组会增加行索引映射复杂度。
