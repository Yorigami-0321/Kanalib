# 候选池（低优先级/远期）

> 上级索引：[../FEATURE-BACKLOG.md](../FEATURE-BACKLOG.md) · 文档地图：[README](./README.md)

| ID | 功能 | 说明 | 依据 |
|---|---|---|---|
| F-015 | 搜索历史与语法帮助 | 最近搜索下拉、语法提示浮层、查询 chips；降低新用户学习成本 | 代码/UX |
| F-016 | CLIP 语义搜索 | 文本→图像向量检索，与标签搜索混合；需要模型、向量存储与 GPU 预算 | PLAN 阶段 4 |
| F-025 | 未使用/低频标签清理 | 标签管理显示 0 使用、低频、仅自动标签，可批量屏蔽/合并 | 代码/UX |
| F-026 | XMP/标签写回 | 显式 opt-in 的 XMP sidecar 导出/写回；首版仍不修改原图 | PLAN §2.2/阶段 4 |
| F-046 | 去重组搜索/排序 | 按路径/名称/大小/可释放空间筛选与排序组，支持键盘下一组（第五轮：待任务 D，未实现） | 代码/UX |
| F-047 | 回收站入口与删除审计 | 打开系统回收站、显示最近移入回收站的文件；不做自动撤销 | 代码/安全 |
| F-048 | 相似扫描分桶/大规模优化 | 当前 10 万约 2.7s；更大库或更低阈值需要分桶/索引 | PLAN §11 |
| F-049 | 保护路径 glob/只读来源规则 | 保护路径从固定目录扩展到 glob；只读来源永远不可移入回收站 | PLAN §6.2 |
| F-064 | ICC/颜色管理 | 读取 ICC 配置并在预览/缩略图中做色彩转换，减少广色域偏色 | 竞品/代码 |
| F-065 | 安装包/签名/自动更新 | MSI/签名/升级通道；便携版已具备，且第一轮已加 pre-flight/许可证/SHA256 清单（`PACKAGE-MANIFEST.txt`） | PLAN 阶段 3 |
| F-066 | 视频/小说扩展 | ffmpeg/mpv 视频缩略图与播放；EPUB/PDF 文本索引 | PLAN 阶段 4 |
| F-067 | 操作撤销/历史 | 标签、星级、收藏等可撤销；删除仍走回收站 | 代码/UX |
| F-068 | 复制图片到剪贴板 | 当前只复制 Prompt/路径；增加 PNG/DIB 复制，便于外部工作流 | 代码/UX |

> 非 UI 候选（F-016/F-026/F-064/F-065/F-066 等）的可复用组件、许可与建议见 [component-research.md](component-research.md)。
