## Wave 1：两条实现线 + 一条 UI 线（可并行）

### 任务 A：UI 小项包（唯一 UI 车道，独占 `app.rs`）

- **文件**：`app.rs`、`search.rs`、`tags.rs`、`dedup.rs`、`platform.rs`、`inspector.rs`；不改 core schema、不写 `settings.rs`（保护路径编辑器归任务 B）。
- **顺序（每项独立提交，不并行）**：
  1. **F-015 搜索历史/语法帮助**：最近查询（settings JSON）、语法提示浮层、查询 chips；不新增 schema。
  2. **F-025 低频标签清理**：标签管理按 0/低频/仅自动排序与筛选；只做展示、屏蔽、复用现有合并；不自动删除标签。
  3. **F-046 去重组搜索排序**：按路径/名称/大小/可释放空间筛选与排序；键盘下一组。
  4. **F-047 回收站入口/审计**：打开 Windows 回收站；记录并展示最近一次移入回收站摘要；不实现应用内撤销。
  5. **F-068 复制图片**：PNG/DIB 写剪贴板；在检查器/右键菜单提供入口（不改 `viewer.rs`）；失败时回退路径复制并提示。
- **验收**：每项隔离数据根截图/UIA；搜索结果/标签计数/组排序/剪贴板内容验证；`cargo check --workspace`；不混入 F-049/F-064/F-067。

### 任务 B：F-049 保护路径 glob 与只读来源规则（核心+设置模块）

- **文件**：`dedup.rs`、`trash.rs`、`state.rs` 保护判定、`settings.rs` 保护路径编辑器；不碰 `app.rs`（本任务独占 `settings.rs`，任务 A 不写该文件）。
- **内容**：
  - 保护路径从固定目录扩展到 glob（`globset`）；保护项优先保留且永远不可移入回收站。
  - 只读来源（Immich/WebDAV/local readonly）同样禁止移入回收站；与现有 `protected_paths` 语义合并，只有一套判定入口。
  - 设置页支持添加/删除 glob、预览命中资产数；持久化到 settings JSON，不加 schema。
- **验收**：glob/只读来源单测；批量去重跳过保护组；单组按钮禁用/拒绝；不影响普通路径；`cargo test -p kanalib-core`。

### 任务 C：F-064 ICC 颜色管理（媒体核心）

- **文件**：`media.rs`/新增 `color.rs`、`state.rs` 缩略图入口、`viewer.rs`（如需读取 ICC）；不碰 `app.rs`、不改 schema。
- **内容**：
  - 用 `lcms2` 读取图片 ICC/EXIF 色彩空间，统一到 sRGB；缩略图与查看器使用同一转换；无 ICC 时保持现有行为。
  - 明确色彩管理开关/性能预算；不重写解码器、不改变缓存键语义（必要时加版本后缀）。
- **验收**：广色域/带 ICC/无 ICC 样本色差对比；缩略图/查看器一致；10k 缩略图性能不显著退化；单测/样本清单；许可记录。
