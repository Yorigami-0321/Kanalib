# 桌面端图片墙改造路线

> 调研输入：`docs/design/ui-references/index.html`（2026-11-16 桌面客户端参考板）。
> 目标不是推翻 GPUI 主布局，而是按「照片最亮、chrome 退后」逐块替换界面语言。
> 状态：四条路线均已落地并完成实机复查；画布手势采用「无级密度缩放 + 中键平移 + 拖拽框选」，不引入第二套自由画布。

## 1. 四条路线

| # | 路线 | 落点 | 状态 |
|---|---|---|---|
| 1 | 内容墙换装：封面卡片 + 类型色码 | 图库网格、分组网格共用 `views::grid::tile` | 已落地第一批 |
| 2 | chrome 退后：窄图标轨 + 顶部常驻搜索 + 可收起面板 | 标题栏、活动栏、侧栏底色与分隔线 | 已落地第一批 |
| 3 | 无界墙手势：画布级平移缩放 | 网格滚轮 / 中键平移 / 密度缩放 / 拖拽框选 | 已落地（框选第三批 + 触控板捏合） |
| 4 | 过程可见：导入灯箱 + 状态点 + 浏览/编辑分态 | 导入进度、来源扫描状态、检查器/查看器 | 已落地（灯箱与状态点第一批，分态第二批） |
| 补 | 来源封面卡 | 侧栏来源行 | 已落地第二批 |

## 2. 已实现

### 2.1 内容墙卡片

- 卡片改为大圆角（`RADIUS_CARD = 12`）独立表面：图片在上、信息页脚在下，hover 提亮并加轻投影。
- 普通图片不加装饰色条；视频用 info 色卡头，损坏/失败用 warning/danger 色条，保持「内容优先」。
- 图片左下角常驻媒体信息：视频显示时长，图片显示分辨率；底部信息行带媒体图标、评级、标签数。
- 选中态用 accent 边框 + 勾选角标；收藏、损坏、失败角标在右上角纵向堆叠，互不遮挡；hover 时页脚出现快速查看提示。
- 分组网格复用同一瓦片，不增加第二套卡片样式。

### 2.2 壳层降噪

- 侧栏面板与活动栏改用窗口底色 `bg`，只有内容卡片使用更亮的 `surface`；去掉活动栏与标题栏的重复分隔线。
- 标题栏左侧新增侧栏开关（`PanelLeft`），侧栏收起后仍可从标题栏恢复，不再只能依赖 `Ctrl+B`。
- 顶部搜索仍是全局唯一搜索入口；本次未新增第二套筛选/搜索控件。
- 窄宽（`<1100`）下搜索容器不再被 flex 压缩，`1024` 宽仍保留输入、历史与语法帮助；占位文案在输入框内自然截尾，不挤压排序/视图/导出按钮。

### 2.3 导入灯箱

- 冷导入（扫描开始时图库为空）自动打开全屏灯箱：阶段、done/total、吞吐、ETA 与当前来源一块显示，缩略图按导入顺序实时流入。
- 每张瓦片可就地打分、收藏，或点击跳回图库定位；灯箱只读核心的运行期导入流（最近 240 条），不新增数据库字段。
- 扫描结束后灯箱保留本次摘要；收起后可从底栏「导入灯箱」重新打开，扫描中也可随时转后台继续。

### 2.4 画布手势

- 三种图标网格支持 Ctrl/Cmd + 滚轮与触控板捏合无级缩放（`0.6..1.8`），标题栏提供缩小、放大与「自动排布」三个入口；系数在停止滚动后合并写入 `ui.grid_zoom`，不会每个滚轮事件都同步打开数据库。
- 缩放按当前顶部行锚定，并撤掉同一次滚轮已经施加的列表滚动；顶部/底部已钳住的滚轮不参与反推，避免锚点被反向推开。
- 网格空白处或卡片上按住中键可上下拖动画布；直接平移 `UniformListScrollHandle` 的像素偏移，不重写虚拟化，也不改变既有选中与键盘导航。
- 在平铺图标网格的空白处按住左键拖出选框：选框实时绘制，经过的卡片即时进入选择；按住 Shift/Ctrl 从现有选择追加。框选不改变卡片点击、Ctrl/Shift 点选与中键平移。
- 框选矩形会夹在列表视口内，只对当前可见行求交；分组视图仍走原有点选/范围选择，不做跨组框选。
- 「自动排布」只做一键回到中等密度、缩放 1.0 与列表顶部——固定网格本身始终自动排布，没有另造自由画布。

### 2.5 来源封面卡

- 侧栏来源行从文字列表升级为 44×44 封面小卡：封面优先 `tile_thumb`、回退 `thumb`，无图时显示 `ImageOff`。
- 卡片同时显示名称、健康绿点、张数与拍摄/修改日期跨度；健康来源只显示绿点，错误/离线才显示状态文字。保留原右键菜单、`Role::Button`、`tab_index` 与 aria 语义。
- 封面与日期跨度按 `shared.revision` 缓存；扫描中只显示状态与数量，扫描结束后的第一帧再计算，避免每帧全量扫库。

### 2.6 浏览/编辑分态

- 图库检查器只保留浏览动作：快速查看、找相似、对比、打开文件、复制、EXIF/哈希信息与损坏修复出口。
- 收藏、星级、手工标签与相册归属迁入查看器顶部编辑条；手工标签仍走同一条 `add_tags` / `remove_tags` 持久化路径，没有第二套写库实现。
- 检查器保留只读手工标签芯片与「在查看器中编辑」入口，选中项仍可一键进入查看器继续编辑。

## 3. 约束与边界

- 保留主图库网格的虚拟化与「图片 + 页脚 + 行留白」行高结构；缩放只按同一公式缩放图片高度，不另建画布。
- 不改数据模型、schema、标签语义与搜索语法。
- 新增颜色一律走 `UiColors` / Ely `Theme` 语义 token，不写死 hex。
- 新增文案走 `t()` / `t_args()`，中英文目录同时补齐。

## 5. 保留边界

1. **框选范围**：当前框选只覆盖平铺图标网格，不做边缘自动滚动，也不做跨分组框选。
2. **轴心**：本轮只做固定网格上的密度缩放与平移，不引入第二套自由画布或自由排布。
