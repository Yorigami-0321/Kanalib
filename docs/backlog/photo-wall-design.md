## 2. 参考图可提炼的形态特征（只借原则，不抄品牌资产）

| 特征 | 观察 | 本项目的落法 |
|---|---|---|
| 布局 | 不规则紧密拼贴，大图（2x2）+ 小图混排，**缝隙极小（≈6–10px）**、直角或极小圆角 | 保持 infinitegrid 混排，行距/列距收紧、圆角降到 ≤2px |
| 导航 | 左侧窄竖条，图标+竖排文字，深色、无边框、选中项用一块圆角高亮 | 左侧边栏 64–72px（可展开到 200px） |
| 叠加信息 | 图片左下角半透明 chip（如「歌单 · 271」），标题压在图上 | 卡片左下角 chip：标签数/星级/收藏；文件名默认隐藏，hover 显示 |
| 层次 | 图片满铺、无卡片边框、阴影极轻或无 | 去掉现在卡片的外描边与浅灰底 |
| 底部 | 常驻播放条（线性阴影） | 换成薄底栏：只放「已加载/总数」与加载进度，不再放筛选控件 |
| 字体 | 中文细黑体、字号克制、字重单一 | 正文 13–14px / 标题 20–28px；不用粗黑 |
| 动效 | 悬停轻微放大/提亮，过渡短促 | 120–180ms ease-out，只动 opacity/transform |

## 3. 信息架构（v2）

```
┌──────┬──────────────────────────────────────────────┐
│ 侧栏 │  墙（整屏拼贴，无限追加）                      │
│ 72px │                                              │
│      │                                              │
│ 搜索 │                                              │
│ 标签 │                                              │
│ 收藏 │                                              │
│ 分级 │                                              │
│ 分组 │                                              │
│ 排序 │                                              │
│ 缩放 │                                              │
│ ──── │                                              │
│ 关于 │  底部薄条：已加载 5,000 / 9,899               │
└──────┴──────────────────────────────────────────────┘
```

- 侧栏是**唯一**的筛选入口：搜索框在顶部（点开后浮出输入），标签/收藏/分级/分组以图标按钮+弹出面板呈现，选中态用高亮块表示，命中数显示在面板里。
- 侧栏可展开（200px）显示文字标签，默认收起到图标列。
- 点击某个标签/分组 = 进入该筛选的「视图」，侧栏顶部显示当前视图名与清除按钮（类似参考图「歌单」视图）。
- 不再有顶部横条；「缩放模式 / 适应屏幕」降级为侧栏底部图标 + 键盘快捷键（W / F）。
- 移动端：侧栏折叠为底部四个入口 + 抽屉。

## 4. 墙（Wall）视觉规范

- 背景 `#0B0B0D`；图片区即为视觉主体，**无卡片底色、无外边框**。
- 间距：列间距 8px、行间距 8px；容器左右留白 12–16px（沉浸感优先）。
- 圆角 2px；hover 时 `filter: brightness(1.08)` + 轻微 scale(1.01)，180ms。
- 叠加层（默认只显示最小信息）：
  - 左下 chip：`标签 12` / `★4` / 心形（收藏）。
  - 顶部右侧：分级角标（R-18 等）用细描边小标记，不做大色块。
  - hover：文件名 + 分组以 1 行省略号出现在底部（渐变遮罩 60px 高）。
- 尺寸档按宽高比：竖图 1x2、横图 2x1、近方 1x1，大图（≥2 倍面积且分辨率足够）用 2x2 强化节奏；避免连续三张同档。
- 空态/加载态：不用 spinner 卡片，用居中细字 + 骨架渐显。

## 5. 详情页（Detail）重做 —— 展示型，不是工作台

目标：像画廊作品页/杂志跨页，而不是桌面应用的「检查器」。

- 布局（桌面 ≥1024px）：
  - 左上角极简返回（← 返回墙），无面包屑、无标题栏。
  - 主图居中偏左，最大不超过视口 72vh，**不描边、不铺棋盘格**（棋盘格只在图片有透明通道时显示，且更淡）。
  - 右侧（或图下方）为信息列：作品名（大字、细字重）→ 元数据（尺寸/时间/分级）用两列细表 → 标签 chips（按类别分组，未知类别默认色）→ 原图/下载入口（有空才显示）。
- 相似推荐：底部横向条（不是网格格子），标题细字「相似」，卡片圆角 2px，hover 提亮。
- 键盘：← → 在相似/相邻之间切换，Esc 返回墙；滚轮在详情页 = 切换上一张/下一张（带方向感知），不缩放。
- 移动端：上图下文，信息折叠为可展开区块。
- 不用工作台的卡片容器、按钮体系、状态栏、快捷键提示条。

## 7. 验收清单（v2 定稿后）

1. 首屏无顶部横条；左侧边栏可收起/展开，键盘可达。
2. 墙缝隙 ≤8px、无卡片描边，混排节奏连续滚动 2000 张无跳动。
3. hover 叠加信息出现/消失不引起布局位移。
4. 详情页在 1440×900 与 1024 宽下都不出现横向滚动，图片不超过视口 72vh。
5. 筛选从侧栏发起，命中数正确，清除后回到全量视图。
6. 对比度：正文对背景 ≥4.5:1，chip 文字 ≥4.5:1。
7. 移动端 390px 宽：侧栏收为抽屉，墙单列/双列。
