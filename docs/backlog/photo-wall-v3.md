## 0. 一句话定位

把"图片墙"做成一个**可栖居的图片空间**：首页没有分页、没有工具栏，你在图片之间移动；导航是一条极窄的黑白"缝"；标签层是排版化的封面墙；详情是全屏作品，UI 压到最低存在感。

判断一条改动的标准只有三个：**它是否让画面更像一个连续空间、是否让 UI 更薄、是否让图片成为主角。**

## 2. 视觉标准（token 级，照此执行）

### 2.1 颜色

| token | 值 | 用途 |
|---|---|---|
| `--bg` | `#070707` | 页面底 |
| `--surface` | `color-mix(in srgb, #070707 90%, #f7f4ee)` ≈ `#0c0c0c` | 边栏纸面、浮层 |
| `--ink` | `#f7f4ee` | 主文字 |
| `--ink-soft` | `color-mix(in srgb, #f7f4ee 55%, transparent)` | 次级文字、未选中导航 |
| `--hairline` | `rgba(247,244,238,.08)` | 发丝线、分隔 |
| `--accent` | **动态合成**（见 §2.1.1），兜底 `#8f8f92` | **只用于两处**：当前项 2px 内描边、极少数状态点 |
| `--accent-2` | `#6a48ff` | 只进背景光晕，不用于 UI |

- 背景光晕：`radial-gradient(circle at 14% 12%, accent 16%, transparent 29%)` + `radial-gradient(circle at 86% 82%, accent-2 20%, transparent 32%)` 叠在 `--bg` 上（Folia 同款，实测值）。
- 噪点：整层伪元素 `feTurbulence`（baseFrequency .92，2 octaves），`opacity .13`，`mix-blend-mode: soft-light`。
- 暗角：`radial-gradient(ellipse at center, transparent 78%, rgba(0,0,0,.52) 100%)`，只压在图上、控件之下。
- **黑白的意思是：界面只用白/灰/黑，强调色只作为"状态"出现，不作为装饰。**

### 2.1.1 动态强调色（2026-11-09 用户：珊瑚红不好看，要跟着图走）

不做固定品牌色。强调色由**当前正在看的图**算出来，规则如下：

**取样**
- 只取视口里权重最高的若干张（可见面积 × 距视口中心权重，取前 6 张），不是全库、不是每一张。
- 每张图在 t256 加载完成后离屏 canvas 缩到 16×16 取像素，丢掉近黑（L<0.18）、近白（L>0.92）、低饱和（C<0.04）的像素；剩下的按"饱和度 × 频次"加权求代表色；结果缓存 `id → color`，一图只算一次。

**合成**
- 多张按可见面积加权平均（在 OKLCH 里平均，不在 RGB 里，否则会发脏）。
- 夹取到"能用"的区间：`L 0.62–0.72`、`C 0.10–0.16`，色相不夹。这个区间保证对 `#070707` 底的对比度 ≥ 4.5:1，且不会刺眼。
- 输出 `--accent` 用 `@property` 注册成 `<color>`，`transition: --accent 600ms cubic-bezier(.2,.7,.25,1)`，颜色平滑过渡而不是跳变。

**时机**
- 滚动**停止**后 300ms 才重算（滚动过程中不重算，避免颜色抽搐）；切页、进详情时立即用新画面的色。
- 详情页用**这一张图**自己的主色，不做聚合——单张作品就是它的主色。

**兜底**
- 找不到可用色（纯灰图/加载失败）→ 保留上一次的值；从未有过 → `#8f8f92`（中性灰）。
- 强调色**永不用于大面积填充**：rail 选中项仍是白底黑字，动态色只出现在细线、描边、内发光、进度点。这样即使某张图的主色很怪，也不会毁掉整屏。

**不做**
- 不做逐像素实时采样、不做 video 式跟手变色、不把主色用于大面积背景。

### 2.2 字体

- 字族：`Inter, "Segoe UI", Noto Sans CJK SC, Source Han Sans SC, PingFang SC, Microsoft YaHei`。
- 层级（只保留四档，不再增加）：`13 / 15 / 20 / clamp(22px, 2vw, 36px)`；详情标题可用 `clamp(28px, 3vw, 44px)`。
- 导航项：14px / 700 / `letter-spacing: .18em`；竖排时 `writing-mode: vertical-rl`。
- 卡片标题：`line-height: .96`、`letter-spacing: -.045em`、最多 3 行、`text-wrap: balance`。
- 所有数字 `font-variant-numeric: tabular-nums`。
- 角标：11px / 800 / `.12em` / 直角 / 底色 `rgba(0,0,0,.62)`——**不用 blur**（每张卡各升一层合成，是整墙最大的 GPU 开销）。

### 2.3 形

- 卡片圆角：**待定**（Q11：0 方正 vs 12 柔和）。
- 缝隙：6px（纵向滚动的密集墙）或 8px（画布方案，Folia 用 128px 格 + 8px 缝）。
- 底部遮罩：`linear-gradient(180deg, rgba(0,0,0,.05) 34%, rgba(0,0,0,.24) 56%, rgba(0,0,0,.92) 100%)`；文字块 inset 17px。
- 焦点/当前：三环 `0 0 0 1px rgba(0,0,0,.62), 0 0 0 4px #fff, 0 0 0 5px rgba(0,0,0,.38)`；"正在看"另用 2px accent 内描边 + `inset 0 0 15px -7px`，两套不叠加。
- hover：按"外扩一个缝隙"算 `scale((w+2·gap)/w, (h+2·gap)/h)` + `saturate(1.08) brightness(1.05)`，不用固定百分比。

### 2.4 材质

- 边栏（默认）：实色纸 `--surface` + `box-shadow: 0 24px 64px rgba(0,0,0,.42)`，**无边框**。
- 边栏（玻璃档）：纸降到 64% 透明 + `backdrop-filter: blur(18px)`；Folia 默认不开 blur，玻璃只作为可选档。
- 浮层面板：`color-mix(bg 92%, ink)` + `blur(18px)` + `0 24px 64px rgba(0,0,0,.55)`，圆角 14px。

### 2.5 动效

- 主曲线：`cubic-bezier(.2, .7, .25, 1)`；出场 `ease`。
- 时长：hover 160ms、选中 180ms、面板 140–180ms、卡片显影 600ms、路由切换 350ms。
- 入场：`opacity 0 → 1` + 上浮 12px，240ms；换页签时走对角线波次（每格 30ms、封顶 340ms，出场远先走、入场近先到）。
- **只动 `transform` / `opacity` / `filter`**；不给容器加 `will-change: transform`（会把每张卡按 1x 栅格化，显存翻数倍）。
- `prefers-reduced-motion` 全关位移，只留 180ms 淡入。

## 3. 十条硬规则（不满足就不算完成）

1. 首页不出现工具栏、标题栏、分页器、页码、"共 N 张"这类脚手架文案（计数只留在边栏底部，小字）。
2. 导航只有一条，宽度固定；展开/收起不推挤内容（浮在内容之上）。
3. 一个状态只用一种视觉通道表达：底色 **或** 文字亮度，不同时改字号/位移/描边。
4. 卡片信息默认隐藏，只在 hover / 焦点 / 详情里出现（不允许常驻信息条）。
5. 角标不 blur、不圆角、不用渐变。
6. 焦点与当前项用内描边，不用外发光。
7. 图片永远 `object-fit: cover`（详情页除外，用 contain），不拉伸、不加棋盘格。
8. 背景层（光晕/噪点/暗角）永不拦截指针。
9. 动效只发生在进入、离开、切换；滚动过程中不做视差。
10. 390px 宽下必须能单手浏览；画布/缩放这类高阶交互在窄屏可以关掉。

## 4. 明确不做

- 不做账号、上传、编辑、评论；云端永远只读。
- 不做多窗口/多面板同屏的工作台式布局（那是桌面端的形态）。
- 不引入第二套 UI 组件库；新增依赖最多一个重型（如 WebGL 或动画库），且需先确认。
- 不做"无限缩放"（除非 Q1 选画布方案，那时缩放是相机的自然结果，不是独立模式）。

## 6. 待确认问题

### A. 空间与首页（最影响形态）
**Q1.** 首页要不要从"纵向无限滚动"改成"二维可平移画布 + 相机缩放"？
- A. 保持纵向滚动（现状）：实现稳、移动端友好、无障碍好，但"无界"只停留在视觉层。
- B. 改二维画布：拖拽/滚轮二维移动、相机 0.52–0.76，最接近模式一；代价是必须做虚拟化、键盘与屏幕阅读器要另设入口、移动端手势冲突。
- C. 混合：默认纵向滚动，**左键拖拽进入画布平移**（2026-11-09 拍板），滚轮仍纵向。
  默认建议：**C**。

**Q1 补充（2026-11-09 拍板）**：右键单击图片弹出"概要"浮层，只放最必要的信息（缩略图、文件名、尺寸/日期/分级、前几个标签、打开详情），不做成第二个详情页。

**Q2.** "随机展示"的粒度？
- A. 每次刷新整页重排；B. 每次从详情返回首页也重排；C. 固定种子、永远同一顺序。
  默认建议：**A**（刷新即换，会话内稳定）。

**Q3.** 首页要不要开场（大标题/版权信息/一行说明），还是进站即满屏图？
默认建议：**进站即满屏图**，品牌只留在边栏顶部。

**Q4.** 首页与标签层之间要不要"过渡画面"（比如相机缩放到标签区），还是直接切页？
默认建议：直接切页，加 350ms 淡入。

### B. 导航
**Q5.** 边栏形态：
- A. 竖排文字页签（Folia 缝：120px 宽、黑白、竖排汉字、页签间 4px）；
- B. 现有图标条（76px，展开 232px）；
- C. 极细线 + 悬浮圆钮（更抽象）。
  默认建议：**A**（和"黑白 + 半透明"最搭，也最不像 SaaS 后台）。

**Q6.** 边栏材质：A. 实色纸面 + 大投影（Folia 默认）；B. 玻璃（64% + blur 18）；C. 纸面为主，鼠标进入时切玻璃。
默认建议：**C**。

**Q7.** 黑白口径（已答一半：珊瑚红不要，改动态取色）：
- A. 界面纯黑白，强调色完全不出现；
- B. 动态强调色（按 §2.1.1，跟随视口里的图合成）；
- C. 动态色 + 固定第二色（`#6a48ff`）分担不同状态。
  默认建议：**B**。

**Q7a.** 动态色的来源：A. 视口内权重最高的几张聚合；B. 只取 hover/最大的那一张；C. 分层（首页聚合、标签页用该标签封面、详情用该图）。
默认建议：**C**（详情单一图色最像"作品驱动"，首页聚合最稳）。

**Q7b.** 更新时机：A. 滚动停止 300ms 后平滑切换；B. 实时跟随（跟手变色）。
默认建议：**A**。

**Q7c.** 色域限制：A. 夹到"可用区间"（L .62–.72 / C .10–.16，保证对比与不刺眼）；B. 原样取图里的主色（可能发脏、发暗）。
默认建议：**A**。

**Q7d.** 用途范围：A. 只做细线/描边/内发光等"状态"；B. 也允许小面积填充块（如选中胶囊的底色）。
默认建议：**A**。

**Q8.** 层级：首页 → 标签总览 → 单标签墙 → 详情。收藏/分级/分组是否也做成同样的"一层封面 → 二层墙"？
默认建议：**是**，四个入口共用同一套两级结构。

### C. 标签层
**Q9.** 标签总览的形态：A. 大封面卡（4:5，底部大字标签名）；B. 排版为主：巨大标签名 + 小缩略图拼贴；C. 按类别（通用/角色/作品/画师）分组的长列表。
默认建议：**A + 按类别分段**（先分段标题，再卡）。

**Q10.** 标签封面规则：A. 按标签名散列固定（重载不变）；B. 每次刷新随机；C. 用户可"换一张"（记在本地）。
默认建议：**A**，以后再加 C。

**Q11.** 单标签墙（第二层）顺序：随机还是按时间倒序？
默认建议：**随机**（和首页一致）。

### D. 视觉与动效
**Q12.** 卡片圆角：A. 0（方正，Folia 语言）；B. 10–12（柔和，贴近你发的截图观感）。
默认建议：**B**（截图观感更讨喜；如果你要"作品集/画廊"语气就选 A）。

**Q13.** 卡片文字：A. 常驻底部大字标题（Folia 式，clamp 22–36px）；B. 只在 hover 时出现的轻量信息条（现状）。
默认建议：**A**（这是"不像网格"的关键，但会遮住一部分图）。

**Q14.** 入场动效强度：A. 淡入 + 上浮 12px（保守）；B. 对角线波次（换页签）；C. 弹簧 + 位移（激进）。
默认建议：**A（首次加载）+ B（切页签）**。

**Q15.** 是否允许新增依赖？A. 零新增；B. 允许一个动画库（motion/framer-motion）；C. 允许动画库 + WebGL（three/pixi）。
默认建议：**B**（如果 Q1 选画布，需要它做相机与手势；否则纯 CSS 也够）。

**Q16.** 背景层：A. 纯 CSS 光晕 + 噪点（现状）；B. 加一层缓慢流动的极光/着色器（如 Radiant）；C. 可切换的"氛围强度"。
默认建议：**A**，先保证不抢图。

**Q17.** 详情页：A. 全屏视觉（图占满，信息浮在图上，Folia 展开卡式）；B. 现在的 62/38 分栏。
默认建议：**A**。

**Q18.** 要不要自定义光标（磁性/放大镜/拖拽手型）？
默认建议：**只做拖拽时的手型**，不做磁性光标。
