给 Kanalib 的四条换脸路线

不必整体推翻 gpui 渲染层。chrome 与卡片语言可以按方向逐块替换：先换内容墙（收益最大），再换侧栏与筛选，最后打磨空态 / 导入 / 查看器。下面每条路线都对应板上的一组参考。

判断标准只有一条：让「照片」成为界面里最亮、最大、最圆的元素，chrome 退为暗色衬托——而不是反过来让面板和分隔线抢戏。

继续避开（IDE 脸来源）

  • 活动栏图标列 + 多面板分隔线
  • 等宽小字号密集表格行
  • 直角、1px 灰边、无投影的卡片
  • 把搜索藏在菜单里而非顶部常驻
